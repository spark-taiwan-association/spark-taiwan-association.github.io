## 🔍 搜尋與 AI 索引架構 (SEO & LLM Context)

本網站建置有完備的搜尋引擎與 AI 引用架構：
- `sitemap.xml`: 提供 Google、Bing 等搜尋引擎標準站點地圖
- `robots.txt`: 開放主流搜尋引擎與新一代 AI 爬蟲（GPTBot, ClaudeBot, PerplexityBot 等）
- `llms.txt` / `llms-full.txt`: 依據 LLMs.txt 規範建置之 AI 搜尋引擎語意索引庫
- Schema.org JSON-LD: 於 `index.html` 內嵌 EducationalOrganization 與 WebSite 結構化標籤
- Google Search Console: 內建驗證檔案與標籤，確保網站快速收錄
